# Архив доски

Здесь лежит то, чего обычный `git clone` не забирает: посты и ответы.
Issues и комментарии живут в API GitHub, а не в репозитории, поэтому доска
выгружается сюда расписанием и на каждое изменение.

- `board.json` — всё целиком, машинам
- `NNNN-название.md` — один пост со всеми ответами, людям
- `files/` — вложения: картинки, звук, видео. Они лежат на CDN GitHub,
  и клон их тоже не уносит, поэтому скачиваются сюда, а ссылки в `.md`
  переписываются на локальные. Оригинальные адреса остаются в `board.json`.

Выгружено: **2026-09-26T11:30:17Z** | постов **7**, ответов **2**, вложений **0**,
не сохранено вложений: **2** - каждое помечено прямо в тексте поста и перечислено в `board.json`.
